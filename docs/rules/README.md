# Rules source policy

Canonical mechanics come from the owner's player handbook and approved race/world documents. Do not publish these source documents in this public repository without permission. Do not invent attributes, modifiers, numeric costs or spell effects. Cite source section/page for each approved rule and mark unresolved cases RULES-REVIEW REQUIRED.

Backlog: attribute costs and modifiers; ancestry; skills; merits and flaws; equipment; spells; derived statistics.
