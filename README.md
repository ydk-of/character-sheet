# Character Sheet — интерактивный лист персонажа

Стартовый проект интерактивного листа персонажа для авторской НРИ. Прототип: основные сведения, локальное сохранение, импорт и экспорт JSON. Игровые расчёты добавим после проверки первоисточников.

## Запуск

Требуется Node.js 22+ и npm:

```sh
npm install
npm run dev
npm test
npm run build
```

## Публикация

После объединения PR в `main` выберите Settings → Pages → Build and deployment → Source: **GitHub Actions**. Workflow публикует сайт по адресу https://ydk-of.github.io/character-sheet/.

## Агенты

Общие инструкции: [AGENTS.md](AGENTS.md). Специализации: [.agents/](.agents/). Это роли для ИИ-исполнителей, а не автоматически запущенные боты. Работа через Issue → branch → PR → утверждение владельцем.

## Правила и безопасность

Исходные книги и частные материалы не публикуются в открытом репозитории без разрешения. См. [docs/rules/README.md](docs/rules/README.md). Сохранение локальное, используйте экспорт JSON.
